## 7. Embedded & Hardware Projects

### 1. Soil Moisture Monitoring System — STM32 NUCLEO-L031K6
- **Hardware Platform:** STM32 NUCLEO-L031K6 (ARM Cortex-M0+ @ 32 MHz)
- **Firmware & Tools:** Bare-Metal C, Keil µVision, ST-LINK/V2-1 VCP, Proteus VSM
- **Sensors & Circuit:** Analog Capacitive Soil Moisture Sensor, 12-bit Successive Approximation ADC
- **Key Technical Highlights:**
  - Engineered a bare-metal C firmware pipeline sampling analog moisture data every 1 second via SysTick timer interrupts.
  - Converted raw 12-bit ADC values using calibration formula: `V = (ADC_Count × 3.3V) / 4095`, mapping sensor range from dry air (4044 counts) to saturated soil (2149 counts).
  - Programmed automated fault detection: readings `< 100 counts` triggered an immediate sensor disconnect error flag.
  - Streamed formatted ASCII telemetry over UART via ST-LINK Virtual COM Port at 115,200 baud for continuous monitoring.
  - Architected 6 modular C source files separating peripheral initialization, ADC acquisition, and UART driver routines.

### 2. Automated Paper Shredder System — Arduino Uno
- **Hardware Platform:** Arduino Uno (ATmega328P)
- **Sensors & Actuators:** Infrared (IR) Obstacle Sensor, L293D / L298N H-Bridge Motor Driver, 12V High-Torque DC Motor
- **Tools & Simulation:** Proteus VSM, Arduino IDE, C++
- **Key Technical Highlights:**
  - Designed an autonomous paper shredder system eliminating manual power switches via optical paper insertion detection.
  - Interfaced an active-low IR obstacle sensor to trigger bidirectional motor control through an H-bridge driver circuit.
  - Implemented motor stall protection and dynamic timeouts to halt cutter blades immediately after paper clearance.
  - Modeled complete schematics and validated digital logic states inside Proteus before breadboard circuit assembly.

### 3. Snake Game Engine on STM32 TFT Display
- **Hardware Platform:** STM32 Microcontroller (ARM Cortex-M series)
- **Display & Interface:** 2.8" ILI9341 Color TFT LCD (320x240 resolution) via high-speed SPI
- **Firmware & Inputs:** Bare-Metal C, Hardware Timers, 4x GPIO Tactile Buttons
- **Key Technical Highlights:**
  - Implemented an embedded Snake game state machine entirely in bare-metal C without third-party graphics engines.
  - Configured high-speed SPI bus transfers to render frame updates, dynamic food generation, and collision coordinates on the ILI9341 controller.
  - Utilized a hardware timer interrupt for precise game-tick cycles and progressive snake velocity scaling upon score increments.
  - Handled 4-way tactile directional buttons with software debounce filters inside the SysTick loop to avoid erratic input triggers.
